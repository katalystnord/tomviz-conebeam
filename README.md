# Cone-beam CT for Tomviz

Explainer for adding cone-beam X-ray CT (lab and industrial scanners) to
[Tomviz](https://github.com/OpenChemistry/tomviz): flat/dark correction,
cone-beam FDK and SIRT, and shared projectors that run on any GPU through
WebGPU, or on a software GPU driver without one.

Page: https://katalystnord.github.io/tomviz-conebeam/

Code: the [`conebeam` branch](https://github.com/katalystnord/tomviz/tree/conebeam)
of our Tomviz fork, going upstream as a series of pull requests.

Walnut images are our reconstructions of the CWI walnut data
([doi:10.5281/zenodo.2686726](https://doi.org/10.5281/zenodo.2686726), CC BY 4.0).
